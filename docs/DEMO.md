# 로컬 시연 순서

1. `py start_connected.py --fixture` 실행 후 팀 API 연결 모드 선택.
2. 사건 목록에서 새 시연 사건 만들기 → 정상 일치 생성.
3. 수사 기록 → 원문 등록 및 고정 → 구조화 실행. fixture는 외부 AI 호출이 없음을 안내.
4. 기관 증빙·연결 → 원천기관 역할 → 가상 Proof 발급·서명 준비 → 등록 기관 지갑으로 MetaMask 서명·저장.
5. 수사 담당자 역할과 등록 매핑 확인 지갑으로 전환 → 통화 후보 선택 → 연결 확인 서명.
6. 증빙 비교·검증 → 검증 실행 및 판정 기록. 서버 요청 ID와 처리 단계를 확인.
7. 처리 중 새로고침했다면 검증 요청 처리 상태에서 기존 요청 상태 조회. UNKNOWN이면 재제출 대신 거래 상태 확인.
8. SUPPORTED 판정과 온체인 상태 확인 → 해시 재계산 및 온체인 대조.
9. 관리자 역할·등록 관리자 지갑 → 사유 입력 → 단계 완료 승인(ACCEPTED) 서명.
10. 종결 사유 입력 → 사건 종결 서명 → 서버 종결 상태 확인.

정상 외에 통화 결과 불일치(CONTRADICTED), 기관 증빙 부족(INSUFFICIENT), 통화 연결 불명확(CALL_REF 없음, INSUFFICIENT)을 각각 새 사건에서 실행합니다. SUPPORTED가 아닌 사건은 단계 완료 승인·종결이 제한되어야 합니다.

로컬 자동 배포 시 공개 Hardhat 테스트 계정 0은 관리자·매핑 확인자, 계정 1은 가상 기관 서명자로 설정합니다. 실제 팀 환경에서는 공유된 등록 계정을 사용하세요. 테스트 지갑에 실제 자산을 보내지 마세요. 모든 자료는 가상입니다.

MetaMask 창이 뜨지 않으면 같은 브라우저에 확장이 설치되어 있는지, 사이트 접근이 허용되어 있는지 먼저 확인하세요. API 모드에서는 지갑이 없을 때 가짜 서명을 만들지 않습니다.
