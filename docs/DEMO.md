# 본선 로컬 시연

1. 기존 서버를 종료하고 `py configure_ai.py`로 본인 PC에 Gemini 키를 설정합니다. `py start_fullproof.py --live`로 실행합니다. 사전 리허설에서 모델 접근 가능 여부와 MetaMask 계정 선택까지 확인합니다.
2. `/integration`의 연결 상태에서 Gemini API/키 설정, 로컬 Chain 31337, 실제 컨트랙트 주소를 보여줍니다. 가상 사건과 가상 기관임을 설명합니다.
3. `기록·증빙 일치` → 사건과 수사 단계 → Claim·Proof 원문 → `기관 서명용 분석 초안 생성` → 대상·행위·시각·결과를 확인합니다. 전화 연결 실패가 행위 미실행을 뜻하지 않는다는 점을 설명합니다.
4. 초안 상태를 확인한 뒤 MetaMask에서 시연용 서명자 #1로 서명합니다. 실제 로컬 거래 영수증과 SQLite 저장 상태를 확인합니다.
5. 사건 이력에서 상세를 다시 열고 저장 상태를 조회합니다. 기록 해시·서명·영수증의 관계를 설명하되, 블록체인이 자료 내용의 진실성을 증명한다고 말하지 않습니다.
6. 시각 불일치 사례를 열어 기록 확인 필요를 보여줍니다. 허위 수사 판정이라고 표현하지 않습니다.
7. Proof 없음과 CCTV 제공만 확인된 사례를 보여줍니다. 실제 열람 증빙이 없으므로 INSUFFICIENT로 보류되고 저장이 비활성화됩니다.

Gemini를 사용할 수 없어 고정 응답 모드로 시연한다면 시작부터 `--fixture`로 실행하고 **고정 응답·AI 호출 없음**을 명시합니다. 지갑 서명 후 로컬 거래는 실제지만, 공공기관 인증이나 운영망 배포가 아닙니다.

Ctrl+C로 종료하면 로컬 Hardhat 체인은 사라집니다. 새 실행의 과거 분석 이력에 STALE_CHAIN이 표시되는 것은 정확한 동작입니다. 심사 직전에 한 번 켜고 시연이 끝날 때까지 서버를 유지하세요.
