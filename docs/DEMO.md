# 역할별 시연 순서

1. 호스트는 --fixture(고정 추출) 또는 --live(실제 Gemini)를 명확히 구분해 실행합니다. 공유는 README의 --share 실행 단계를 따릅니다.
2. 홈의 ‘수사담당자로 시작’ → 수사담당자 대시보드 → 시연 사건 선택하기 → 정상 일치 선택 → 선택한 시연 사건 열기. 새로 시작하려면 ‘새 시연 회차로 시작’ 체크.
3. 수사 기록 → 원문 등록 및 고정 → 구조화 실행 → 행동·성공 여부·대상·시각·근거 문구 확인.
4. 상단 역할을 원천기관으로 변경. 원천기관 증빙 데스크의 같은 사건을 열고, 기관 증빙 제공 → 가상 Proof 발급·서명 준비 → MetaMask 기관 계정 서명·저장.
5. 기록 확인 완료 확인 후 수사담당자으로 전환. 같은 사건 → 증빙 연결 → 기록 완료 증빙 선택 → 선택한 통화와 연결 확인 → 매핑 확인 계정으로 서명.
6. 증빙 비교·검증 → 검증 실행 및 판정 기록 → 처리 상태·서버 결과·온체인 기록 확인.
7. 해시 재계산 및 온체인 대조. 새로고침해도 기존 요청 조회로 이어서 확인.
8. 관리자로 전환. 관리자 검토 대시보드에서 같은 사건 → 관리자 확인 → 사유 작성 → 단계 완료 승인(ACCEPTED) → 관리자 지갑으로 서명.
9. 서버 종결 가능 조건 확인 → 종결 사유 → 사건 종결 서명 → 종결 상태 확인.
10. 수사담당자으로 돌아오면 ‘증빙이 뒷받침하는 검증’에 종결 사건의 최신 SUPPORTED도 포함됩니다. 설명 문구를 확인합니다.

결과 불일치(CONTRADICTED), 증빙 부족(INSUFFICIENT), 연결 근거 부족(CALL_REF 없음, INSUFFICIENT)도 각각 선택해 확인합니다. 이 사례는 관리자 단계 완료 승인·종결이 제한되어야 합니다.

기본 로컬 배포에서 Hardhat 공개 테스트 계정 1은 기관, 계정 0은 매핑 확인자·관리자입니다. 실제 운영 지갑·자산을 사용하지 않습니다. 역할 선택은 인증이 아니며 서명은 등록된 지갑으로 수행합니다.
