# 업무 화면 문구 정리

2026-10-31. 단계별 현황 변경을 되돌린 기존 Workspace Design 버전 기준입니다. 앞선 복수 단계 체크리스트 수정은 포함하지 않았습니다.

## 변경

- 홈의 큰 DEMO 표시를 WORKSPACE로 변경했습니다. 평가용 예제 데이터 및 역할 선택이 실제 로그인 인증이 아니라는 안내는 하단에 유지합니다.
- 사건 선택, 증빙 발급·서명 준비, 결과 새로고침 등 업무 중심 버튼·메뉴로 정리했습니다.
- 반복되던 긴 시연 안내를 간결한 환경 표시와 접이식 환경 안내로 통합했습니다.
- 기존 API 사건 제목의 알려진 ‘가상 실종 사건’ 접두사는 화면에서만 ‘실종 사건’으로 표시합니다. 서버 원문·해시·서명 데이터는 변경하지 않습니다.
- Mock 실행에는 ‘로컬 · 미서명·온체인 미저장’, 고정 AI에는 ‘고정 추출’, 실제 API에는 테스트 체인 표시를 유지합니다. 로컬 승인 인장도 로컬 기록임을 표시합니다.
- 배경색·폰트·로고·역할별 디자인과 API·서명·종결 규칙을 유지합니다.

## 확인

- 프론트엔드 테스트 58개 통과. 역할별 화면 이동, 환경 표시 유지, DEMO 배지 제거, 승인 실패·중복 클릭 보호 포함.
- TypeScript 및 Vite 빌드 통과.
- 복원한 기존 ZIP 대비 백엔드 소스 바이트 비교 통과. PRODUCT_COPY_SOURCE_CHECK.json 참고.
- 이번 문구 수정본으로 실제 Gemini·MetaMask·Hardhat 전체 흐름과 브라우저 시각 검사는 실행하지 않았습니다. 기존 테스트 보고서는 작성 당시의 결과입니다.

## 실행

기존 README의 설치·실행 절차를 사용합니다. API 연결은 키를 개인 로컬 환경에 설정하고 `py start_connected.py --live`를 실행하세요. 프론트엔드 확인은 `py start_frontend.py`로 시작합니다. .env 및 키는 ZIP이나 Git에 포함하지 않습니다.
