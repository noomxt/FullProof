# 다크 모드 로고 변경

보내주신 흰색 SVG를 원본 바이트 그대로 사용했습니다. 홈 상단과 업무 화면 사이드바는 동일한 BrandLogo 컴포넌트를 사용하며, data-theme=dark에서 흰색 로고를 표시하고 light에서는 기존 PNG를 표시합니다. 다크 모드의 흰색 로고 배경 상자를 제거했습니다. API 연결과 업무 로직은 변경하지 않았습니다.

확인: 제공 SVG와 배포 자산 바이트 일치, 기존 프론트엔드 테스트 61개 통과, TypeScript 및 Vite 빌드 통과. 브라우저 시각 검사는 이번 변경에서 별도로 실행하지 않았습니다.
