## 재현 명령

fullproof에서 `npm.cmd ci`, `npm.cmd test`, `npm.cmd run build`, `py -m unittest discover -s tests -p "test_*.py"`.

백엔드의 가상환경 Python으로 `-m unittest discover -p "test_*.py"`를 team-backend에서 실행합니다.

서버를 모두 종료한 뒤 `py test_connected.py --browser`. 브라우저가 없으면 `npx.cmd playwright install chromium`으로 설치합니다. 연결 테스트는 서버를 직접 시작·종료하고 고정 응답으로만 실행합니다.

## 실제로 실행하지 않은 부분

- **실제 Gemini API 호출:** 이 작업 환경에 사용자 키를 제공받지 않았으므로 호출하지 않았습니다. py configure_ai.py로 사용자 PC에 키와 사용 가능한 모델을 입력한 뒤 --live로 실행해야 합니다. 키 존재 표시만으로 API 인증이나 모델 사용 가능성이 확인된 것은 아닙니다.
- **실제 MetaMask 확장 프로그램:** 브라우저 자동 테스트는 RPC 지갑 어댑터입니다. 사용자 PC에서 계정 가져오기·네트워크 연결·서명 승인까지 수동 확인해야 합니다.
- Windows 통합 실행 도구, 공공기관 API, 독립 Proof 발급 진위 인증, 운영 네트워크, 테스트넷, 다중 서버·부하·운영 보안 감사는 확인하지 않았습니다.
- 원본 체크포인트 경로와 새 분석 경로를 통합한 전체 복구 기능은 완성되지 않았습니다. 여기의 SQLite 재동기화는 확인된 한 분석의 사건 스냅샷 복원 범위입니다.
- 팀 GitHub 저장소에 자동 반영하거나 병합하지 않았습니다. ZIP 안에서 통합한 코드입니다.

`LOCAL_TEST_EVIDENCE.json`은 테스트 중 실제로 생성된 로컬 거래 해시와 결과입니다. 테스트 종료 시 메모리 체인도 종료했으므로 이 해시를 현재 운영망이나 공개 탐색기에서 조회할 수 있다는 뜻이 아닙니다. 고정 응답 결과의 실행 방식은 SQLite 분석의 execution 정보로 함께 확인해야 합니다. 원본 컨트랙트 스키마 자체에는 AI 실행 방식 필드가 없습니다.

브라우저 스크린샷은 내부 배치 확인에만 사용했으며 ZIP에 포함하지 않습니다. 최초 네 Mock 화면의 데이터와 팀 API 데이터는 여전히 구분됩니다.
