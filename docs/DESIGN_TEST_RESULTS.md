## 제한과 별도 확인 필요

- 관리형 미리보기 주소는 HTTP `terminal.local`입니다. 업무 화면은 기존 HTTPS/localhost 보안 검사를 유지하므로 해당 미리보기에서는 보안 안내가 나타납니다. 이 제한을 피하기 위해 보안 검사를 끄지 않았습니다. 홈 외 업무 화면의 이번 버전 브라우저 시각 검증과 전체 로컬 체인 E2E는 다시 실행하지 못했습니다.
- 세 업무 화면·승인 효과의 기능은 jsdom 컴포넌트 테스트와 브라우저 Mock 로직으로 검증했습니다. 실제 MetaMask 확장·Gemini 호출·실제 승인 거래에 대한 새 수동 테스트는 수행하지 않았습니다.
- 모바일 반응형 CSS와 동작 줄이기를 지원하지만 이번 변경의 모바일 실제 브라우저 검증은 수행하지 않았습니다.
- `ROLE_UI_RESULTS.json`, `LOCAL_TEST_RESULTS.json` 등 기존 기록은 이전 버전의 검증 자료입니다. 이번 변경의 결과로 해석하지 마세요.
- `tests/role-visual.mjs`, `tests/browser_connected.mjs`는 새 홈 경로/명칭에 맞췄지만 이번 환경에서는 다시 실행하지 않았습니다.
- 상시 공유 서버는 배포하지 않았습니다. 운영 서버의 인증·기관별 접근 제어·영속 체인·HTTPS 구성도 이번 UI 수정 범위 밖입니다.

## 본인 컴퓨터에서 확인

1. ZIP 압축을 새 폴더에 풀고 `fullproof` 폴더에서 PowerShell을 엽니다.
2. `py start_frontend.py` 실행 후 `http://127.0.0.1:5173`을 엽니다.
3. 홈에서 수사담당자·원천기관·관리자를 각각 선택하고 왼쪽 ‘홈’으로 돌아옵니다.
4. 가상 정상 일치 사례의 기록 등록 → 추출 → 기관 증빙 → 매핑 → 검증을 진행합니다.
5. 관리자로 결과 확인을 저장하면 인장이 나오지 않아야 합니다. ‘단계 완료 승인’을 저장하면 ‘가상 승인’ 인장이 나타나야 합니다.
6. 실제 연결은 로컬 키 설정 후 `py start_connected.py --live`로 실행합니다. 저장된 모드가 Mock이면 업무 화면의 연결 설정에서 팀 API로 변경합니다.

역할 선택은 로그인이나 접근 권한 인증이 아닙니다. 모든 자료는 가상이며 AI 판정과 관리자 승인은 별도입니다.
